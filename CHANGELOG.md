# Changelog

## 1.1.0 (unreleased)

### Security

* **Removed** an unused AES decryption helper with a hard-coded key and IV committed to the
  repository. If that key was ever used to protect real secrets, rotate them.
* SSH (`mq-deploy-ssh`): host keys are now verified against `~/.ssh/known_hosts`
  (`mq.ssh.strictHostKeyChecking=yes|accept-new|no`, `mq.ssh.knownHosts`). Previously every host key
  was accepted silently (man-in-the-middle).
* SSH: the MQSC script is sent through stdin (`mq.ssh.exec=runmqsc %s`) instead of being interpolated
  into `echo "<script>" | runmqsc`, which allowed shell command injection through script contents or
  properties. Legacy two-placeholder templates still work, with the script safely quoted.
* The queue manager name is validated before building any command.
* `ace-deploy`: TLS certificates are verified (they were never verified, even with `useSSL`).
  New `ibm.ace.ssl.insecure` to opt out explicitly. Trust/key stores no longer change the global
  `javax.net.ssl.*` properties of the Maven JVM.
* Credentials can be read from `settings.xml` (`ibm.ace.serverId`, `mq.serverId`), including passwords
  encrypted with `mvn --encrypt-password`.
* XML parsing (`.project`, `.policyxml`, `.mxml`) is protected against XXE.
* `mq-deploy-pcf` uses MQCSP authentication and builds the TLS socket factory from `mq.keystore`
  (the parameter was ignored before).

### Fixes

* `mq-deploy-ssh` multi-instance: checks `dspmq -m <QM>` (it checked any running queue manager),
  connects once instead of once per script and closes every SSH session.
* `mq-deploy-pcf`: queue manager and PCF agent connections are closed.
* `ace-deploy` fails when a bar is not deployed or the server does not answer.
* `ace-properties` restores `System.out` (it stayed redirected for the rest of the build).
* `ace-keywords` uses a fresh temporary directory per bar (stale files from a previous run could end up
  in the bar), restores the original bar on error and fails the build on errors.
* `ace-mqs` no longer writes `null` or empty queue names and removes duplicated queues.
* Local commands (`ace-create-tests`, `ace-verify`) no longer hang when a command writes a lot to
  stderr, and paths with spaces are supported.
* Goals no longer swallow exceptions with `printStackTrace()`; errors fail the build with a clear message.
* Policy values with `\`, `=`, `:` or `#` are escaped in the generated properties files.
* Resource leaks (readers, zip files, temporary files) fixed.
* `ace-compile-tests` is now a real goal (the class had no `@Mojo` annotation).
* `ibm:help` is generated by the plugin tools (replaces the archetype's "touch.txt" example goal).

### Build

* Dependencies updated: Jackson aligned through `jackson-bom` (2.9.8/2.14.1 were mixed), JSch replaced by
  the maintained fork `com.github.mwiede:jsch` (OpenSSH/ed25519 keys, rsa-sha2), Lombok 1.18.36 (builds on
  JDK 17/21), commons-io, zip4j, mustache, unirest, MQ client, Maven API 3.9.
* The `release` profile is no longer active by default (every `mvn verify` tried to sign with GPG).
  Publishing moved from OSSRH (shut down in 2025) to the Central Portal (`central` server id).
* The parent POM is no longer needed. Removed the abandoned jgitflow plugin.
* Unit tests (JUnit 5, embedded SSH server) and GitHub Actions CI (JDK 11/17/21) with compile-only
  stubs for the proprietary IBM jars (`ci/install-ibm-stubs.sh`).

### Upgrade notes

* SSH deployments need the MQ servers in `known_hosts` (`ssh-keyscan -H <host> >> ~/.ssh/known_hosts`) or
  `-Dmq.ssh.strictHostKeyChecking=accept-new`.
* `ace-deploy` with self-signed certificates needs `ibm.ace.sec.truststore` (or `ibm.ace.ssl.insecure=true`).
* `ace-deploy`, `ace-keywords`, `ace-mqs`, `ace-doc`, `generate-pom` and the policy goals now fail the build
  on errors that used to be only logged.
* The configuration element `<enviromentProperties>` is still accepted; the new name is `<environmentProperties>`.
